# BLS12-381-SHAKE-256 Pseudonym Test Vectors

These test vectors, and the matching ones in `../bls12-381-sha-256/`, are
generated by the scripts in `NymTestGeneration/` (see its README) and copied
here from `NymTestGeneration/outputs/`. Do not edit them by hand; change the
inputs in `NymTestGeneration/inputs/` and regenerate.

Both ciphersuites have the same set of cases:

- `generators.json`: L + 1 = 11 generators, M + N + 1 = 7 blind generators and
  the committed disclosure generators Y_0 and Y_1.
- `nymCommit/`: CommitWithNym, 001–004.
- `nymSignature/`: BlindSignWithNym and VerifyFinalizeWithNym, 001–007.
- `nymProof/`: ProofGenWithNym and ProofVerifyWithNym, 001–011 and 101–105.
  Each proof names the signature it uses in its `signatureFile` field.
